# Fogo — Customizable Chrome Productivity Extension & Modular Workspace

> Fogo is a customizable Chrome productivity extension featuring a modular new tab dashboard, developer integrations, trading widgets, and 22 dynamic themes. Engineered by Dreainno on Manifest V3, Fogo provides a modular, drag-and-drop workspace where traders (charts, portfolio) and developers (GitHub PRs, Asana, Google Calendar, To-Dos) arrange widgets freely across 22 aesthetic themes with 100% local-first privacy.

## Key Features & Differentiators

### 1. Modular Drag-and-Drop Workspace (Developer & Trading Dashboards)
- Fully customizable new tab dashboard with 4 fast-switching workspace profiles (Work, Personal, Study, Trading).
- Arrange widgets freely for developers (GitHub PRs, Asana, Google Calendar, To-Dos) and traders (charts, portfolio, watchlists).

### 2. Offline Executive AI Morning Briefing
- Intelligent copilot delivering structured morning briefings (weather outlook, priority to-dos, motivational focus anchors, market sentiment).
- Powered by a deterministic zero-cost offline synthesizer out-of-the-box.
- Optional user-supplied Gemini or OpenAI API keys for real-time dynamic generative updates without recurring API markups.

### 3. Tab Stash & RAM Saver
- One-click session hibernation releasing background render processes in Google Chrome.
- Reclaims up to 2.8 GB of physical RAM on multi-tab workspaces.
- Restores tabs individually or in categorized batch workspaces.

### 4. 22 Artisanal Themes & 11 Clock Engines
- Curated color harmonies spanning Cyberpunk Neon, Tokyo Twilight, Obsidian Dark, Nord Arctic, Forest Canopy, Swiss Dial, Nixie Tube, and Split Flip clocks.

### 5. Acoustic Focus Soundscapes
- Built-in sound engine with ambient audio channels: Lo-Fi beats, Cafe atmosphere, Deep Rain, Forest, and Pink/White noise for flow state deep work.

## Privacy & Security Verification
- **Manifest V3 Compliant**: Uses modern declarative APIs that prevent background script abuse and respect browser resource limits.
- **Local-First Storage**: User notes, bookmarks, settings, and habits never leave the local machine.
- **Zero Third-Party Cookies or Trackers**: No Google Analytics, no Meta Pixel, no tracking telemetry.
